从备份还原

留空时使用当前 WEB_PASSWORD

      

      
      
      

        
        
      

    

  

  

    

    

      

        

          
导出迁移包

          
迁移包包含凭证、凭证状态、设置、备份端配置和 CPA 非连接类设置。

        

        
      

      

        
导出会停止当前环境自动刷新，并用当前 WEB_PASSWORD 加密迁移包。

        
CPA Base URL 和管理 Key 不会写入迁移包，导入后需要重新配置连接信息。

      

      
      
      

        
        
      

    

  

  

    

    

      

        

          
导入迁移包

          
这会覆盖当前凭证、凭证状态、设置、备份端配置和 CPA 非连接类设置。

        

        
      

      

        
导入成功后自动刷新保持关闭，需要检查后手动开启。

        
导入会恢复迁移包中的 S3 Secret Key，并清空 CPA Base URL 和管理 Key。

      

      
      
      

        
        
        
留空时使用当前 WEB_PASSWORD
